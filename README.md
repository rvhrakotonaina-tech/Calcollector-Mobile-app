# Calcollector

**Calcollector** is a modern, feature-rich Android calculator app designed for productivity and ease of use. It features a clean Material Design 3 interface, responsive layouts for all device types, and advanced history management.

---

## 🚀 Features

### 🔢 Smart Calculator
*   **Precision Math**: Reliable arithmetic evaluation.
*   **Live Preview**: See your result in real-time as you type.
*   **Copy & Paste**: Long-press on formula or result to copy to clipboard or paste equations.

### 📜 Advanced History
*   **Full History Log**: Keep track of all your past calculations.
*   **Entry Editing**: Made a mistake? Click the **Edit** button in history to modify an expression—the app automatically recalculates and updates the entry.
*   **Export to PDF**: Generate professional PDF reports of your calculation history with one click.
*   **Summation (Total)**: Select multiple history entries to calculate their aggregate sum.

### 🎨 Design & Experience
*   **Responsive Layouts**: Optimized for phones and tablets. Features a dedicated **side-by-side landscape mode** for maximum efficiency on large screens.
*   **Dynamic Theming**: Smooth, animated toggle between **Dark** and **Light** modes.
*   **Edge-to-Edge**: Fully immersive UI that respects system navigation and status bars.

## 🛠 Tech Stack
*   **Language**: Java
*   **UI Framework**: Android XML with Material Components (M3)
*   **Architecture**: Android Jetpack (Edge-to-Edge, ConstraintLayout, etc.)
*   **Storage**: SharedPreferences for persistent history and theme settings.
